# 发布前隐私与敏感内容检查

本仓库从独立的发布目录建立，仅显式选取文档、脚本、规则模板、材料清单和结果摘要，没有直接对原始工作目录执行 `git add .`。

## 在原始工作目录中发现并排除

- 原始解锁结果含手机 ADB / Fastboot 序列号。
- MTKClient 设备状态、连接日志及硬件参数文件可能含硬件 UID、存储标识、MEID/SOCID 等。
- nvram、nvdata、nvcfg、protect、proinfo、oppo_custom、seccfg 等原始分区备份可能含设备唯一数据或用户相关信息。
- 原始 udev 规则含本机用户名；发布模板已换成 `YOUR_LINUX_USER`。
- 工作日志和脚本含本机绝对路径；发布文件改用相对路径。
- Git 全局配置中的私人提交邮箱不用于本仓库提交；使用所发布账号的 GitHub noreply 邮箱。
- APK/JAR、反编译输出、原始 OTA 查询脚本和响应、截图、抓包、终端历史、虚拟环境、授权凭据均未复制。

不上传这些文件，也不上传它们的个人标识哈希。备份在原工作目录本地保留。

## 有意保留的非唯一信息

机型、芯片、系统版本、安全补丁日期、镜像通用 SHA256、公共发布者和来源 URL，以及必要的分区名称、固定补丁偏移和工程指令。
这些信息用于复现和界定适用范围；通用镜像哈希不应误认为设备序列号。

## 检查范围

发布前执行以下检查，机器可读结果记录于 `evidence/publication-review.json`：

1. 对所有待提交文本检查本次已知序列号、本机用户名/路径、私人邮箱及原始硬件标识。
2. Gitleaks 对发布目录及最终 Git 提交历史扫描常见 Token、密码、私钥等。
3. 人工逐项核对文件清单：无设备备份、固件镜像、日志、图片、隐藏凭据或符号链接。
4. 确认新增 Git 历史从已审阅内容开始；没有带入原始研究目录历史。
5. 离线生成器对原始本机输入生成的文件仅放在仓库之外，结果与当时已刷入镜像逐字节相同；错误输入被拒绝。

扫描结果只描述上述范围，不代表发布了原始设备材料供外部复核。仓库不会接收敏感分区备份作为示例或附件。
